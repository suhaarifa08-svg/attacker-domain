# CYBER NOTES | Attacker Simulation Console

An interactive, frontend-only cybersecurity operations center (SOC) and threat simulation console designed for educational training and security demonstrations.

## 🚀 Features & Capabilities
* **Dynamic Matrix Background**: Custom canvas-rendered red matrix rain animation for a real-time hacker console atmosphere.
* **Live Activity Feed**: Real-time logging system that tracks system events, login attempts, and alert logs.
* **Interactive Simulation Controls**: Trigger simulated attacks, test login authentication sequences, start/stop monitoring feeds, and clear event logs dynamically.
* **Login Pattern Simulation**: Step-by-step authentication breakdown simulating success/failure status with animated progress bars.
* **Real-Time Network Visualization**: Animated SVG orbit and node-map visualization mimicking security telemetry traffic.
* **Emergency Alert Overlays**: Full-screen simulated security alert modals with audio-visual cues and acknowledgement flows.

## 🛠️ Tech Stack
* **Frontend**: Pure HTML5, CSS3 (Custom Grid layouts, CSS Animations, Custom Variables)
* **Scripting**: Vanilla JavaScript (ES6+, DOM Manipulation, Interval State Management)
* **Styling & Aesthetics**: Cyberpunk/Terminal-themed UI with responsive media queries for mobile and desktop screens.
